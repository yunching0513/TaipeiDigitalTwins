# 台北數位孿生沙盤 Taipei Urban Digital Twin

以瀏覽器 WebGL 打造的台北市北區 3D 數位孿生系統：**46,000+ 棟建築**、真實河川地理（淡水河、基隆河、雙溪、磺港溪）、霓虹路網，結合**空間系統動力學 × AI 推演迴圈**的都市情境模擬沙盤。

靈感來自 [One Prompt, 46,000 Buildings](https://milanjanosov.substack.com/p/one-prompt-46000-buildings-my-first)（Milan Janosov 的曼哈頓 3D 數位孿生實驗），並整合北士科專家工作坊預填單六大領域（土地生態、建築、都市微氣候、防洪排水、交通、能源）的指標架構。

## 功能

### 🏙️ 3D 城市沙盤
- **46,000+ 棟建築**：依六大分區真實都市紋理程序化生成（士林街屋、北士科科技園區大樓、社子島低層聚落、關渡平原農舍…），每棟高度／街廓走向／密度皆按分區特性配置
- **真實地理**：淡水河、基隆河、雙溪河道與六大分區（北士科園區、洲美、社子島、關渡平原、士林市街、北投）的近似真實輪廓
- 霓虹路網、Bloom 光暈後製、完整鏡頭控制（拖曳旋轉／縮放／點擊分區／飛往分區）

### 📊 五大指標圖層
EUI（建築能耗）、地表溫度、淹水深度、綠覆率、交通風險 —— 全城建築依所屬分區指標即時著色（磚紅=高風險 → 琥珀 → 河青=良好）。

### 🔮 情境推演（4輪 × 3年，2026 → 2038）
六種情境：BAU、綠建築容積獎勵、極端降雨 100mm/hr、熱浪＋AI資料中心進駐、智慧微電網＋儲能、海綿城市藍綠基盤。

雙推演引擎：
1. **本地系統動力學引擎**（預設，離線可用）——內建跨領域回饋鏈：綠覆率→地表溫度→空調用電；淹水→供電設施→能源韌性；土地開發→逕流→淹水…
2. **Claude AI 引擎**——由 Claude 作為空間系統動力學引擎逐輪推演。在瀏覽器直連 Anthropic API（`anthropic-dangerous-direct-browser-access`），以 JSON Schema 結構化輸出保證回傳格式。API Key 僅存於使用者瀏覽器 localStorage。

每輪推演輸出跨域影響鏈事件（受影響分區在沙盤上閃爍脈衝標示）與關鍵動態紀錄。

### 🗺️ OSM 真實建築（選用）
一鍵從 OpenStreetMap（Overpass API）載入士林北投一帶的**真實建築足跡與高度**，以真實輪廓擠出 3D 量體取代程序化建築，並依分區歸屬參與指標著色。

## 快速開始

```bash
npm install
npm run dev     # 開發模式 http://localhost:5173
npm run build   # 產出 dist/
```

## 專案結構

```
src/
├── App.jsx        # UI 面板：情境、引擎、圖層、KPI、推演紀錄
├── scene.js       # Three.js 場景：InstancedMesh 建築、河川、路網、分區、bloom
├── geo.js         # 分區多邊形／河川（經緯度）、平面投影
├── procgen.js     # 程序化城市生成（46,000+ 棟、分區紋理參數）
├── sim.js         # 雙推演引擎（本地系統動力學 + Claude API）
├── osm.js         # Overpass API 真實建築載入
└── constants.js   # 指標、情境、初始狀態、色階
```

## 免責聲明

數值為系統動力學／AI 推演之**示意結果**，非物理模型輸出。正式模擬仍需接入 SWMM、ENVI-met、EnergyPlus 等領域引擎與實測資料。分區輪廓與河道為近似幾何，供沙盤溝通使用。
